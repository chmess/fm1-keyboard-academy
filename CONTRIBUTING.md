# Contributing

Contributions are welcome, especially beginner exercises, accessibility fixes,
translations, hardware test reports and compact UI improvements.

Before opening a pull request:

1. keep exercises short and focused on one learning objective;
2. include only original, traditional or clearly public-domain melodies;
3. run `bash tests/run.sh`;
4. build the PI32v2 firmware when changing target code;
5. state clearly whether testing used the host, simulator or physical hardware;
6. do not include device backups, private logs, credentials or proprietary voice banks.

Changes must retain the applicable license headers and the SDK/linking notices.
